# База знань HR-політик

Кожен файл — один документ для ChromaDB. На чанки не ділимо: документи
короткі й цілісні, а сплітер розрізав би правило посередині.

Цей README у колекцію не потрапляє: `load_documents()` пропускає його
за іменем.

Дані навчальні та вигадані. Жодна з політик не є реальним документом
компанії й не є юридичною консультацією.
